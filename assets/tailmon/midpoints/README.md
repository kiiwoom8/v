# Tailmon halfway drawings

Forty drawn halfway poses for the intervals of the 24 routines that RIFE cannot interpolate (it draws two overlapping translucent bodies): lying down, rolling, turning, the pounce, the play bow. Kim had them drawn with GPT Image on 2026-11-28 from each interval's before-and-after drawings. `midpoints.json` names each drawing's action and 1-based gap (gap 1 runs from the seated pose to the entry drawing; gap 8 back to it).

`tools/assemble_tailmon_routines.py --midpoints assets/tailmon/midpoints` sizes and places each drawing where it overlaps both neighbours best, then RIFE draws the two quarter steps either side of it. A quarter step that still ghosts holds the drawing it leaves.

The prompts follow.

Built-in GPT Image used the existing before-and-after drawings as visual references. After the one-paw stretch sheet was rejected, the tool returned each of its five drawings separately from the relevant endpoint pair.
