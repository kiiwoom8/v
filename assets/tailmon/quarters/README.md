# Tailmon transition drawings

These 43 transparent PNGs were made with built-in GPT Image from pairs of existing desktop Tailmon poses. The manifest uses zero-based samples on the 33 ms animation timeline. Each drawing is fitted between the source samples on either side. The six tail-windmill cels keep the seated body steady while the tail sweeps and curls.

Rebuild the source animations with the bridge and midpoint art first. Then run `python tools/patch_tailmon_quarters.py assets/tailmon/animations assets/tailmon/quarters assets/tailmon/animations` before packing `motion.bin`.
